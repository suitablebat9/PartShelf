Getting started

  1. Create storage areas for your room, cabinet or drawers. Parent areas include their sublocations when browsing.
  2. Add a component with a name and quantity, or import a CSV. Optional details can be added later.
  3. Download labels for your parts.
  4. Create a project and add required quantities.

USD is used for prices. Owners and admins can download inventory and uploaded files from Inventory or Team management.

Inventory CSV import

Download the template, edit it in your spreadsheet program, and save as UTF-8 CSV. Keep the column names; remove the example row. Only name is required. Use decimals without currency symbols or thousands separators.

name_id is your internal part number and defaults to the name. code defaults to that number. Each must be unique. Imports create new components; they never overwrite existing records.

stock is current quantity, unit_price is per-unit cost, purchase_quantity is the original purchase quantity, and purchase_pack is the minimum pack size to buy. Blank stock/price defaults to zero; blank unit defaults to pcs; blank pack size defaults to one. Purchase totals are calculated from quantity × unit price.

storage must match an existing full path (for example, Lab / Cabinet / Drawer). Blank means unassigned. New category names are created automatically. Separate tags with commas inside a quoted CSV cell. Other template columns store supplier details, descriptions, thresholds and specifications. Attachments are added separately from component editing.

Files are limited to 1,000 rows and 2 MB. Fix any reported row errors and upload again. Preview before confirming; an expired or changed preview must be recreated. All changes are applied together, or none are.

Projects, BOM imports & shopping

Open a project and choose Import BOM. The BOM template has name_id and quantity. Parts must exist in this workspace. Duplicate rows are summed. “Update listed parts” sets their required quantities and keeps unlisted parts; “Replace” removes unlisted parts from the project. Neither changes stock.

Duplicate project copies its name, description and parts list into a new project. It does not copy build history or deduct stock.

Shopping list groups shortages by supplier and exports CSV with links, exact unit costs and rounded whole-pack purchases. It uses saved prices, not live supplier quotes. Change the number of builds to plan repeated assemblies.

Build deducts the listed quantities only when all parts are available. Build history offers Undo to restore a deduction once. A deleted component prevents undoing its old build.

Quick stock and bulk changes

Select rows in Inventory to move components, add/remove tags, or add/remove stock. Select all applies only to the visible search results. Changing search or filters clears the selection. The quantity is applied to each selected part in its own stock unit; review the before/after values before confirming.

Use the ± stock button on a row to adjust one part. Removing more stock than available blocks the entire change. Stale previews cannot overwrite changes made by another staff member.

Camera and barcode scanning

Open the scanner on an HTTPS connection and allow camera access. Hold the label steady in good light. The camera stops when a code is found, when you stop it, or when you leave the page. Review the decoded value and choose Find component.

If access is denied or you have no camera, scan a saved photo or type the identifier. Camera/photo processing stays in your browser. Scanned web addresses are treated as search text and are never opened automatically. A USB scanner can type directly into inventory search.
