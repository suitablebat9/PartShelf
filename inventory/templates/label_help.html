Size, margins and printing

Choose a preset or enter the width and height in inches. Each PDF page matches that physical size. Set each margin independently; zero removes extra code padding while keeping QR codes square.

Select QR code, Code 128 barcode, or no code. Text scales down to fit; the font size is a maximum. Fonts support Latin text and common electrical symbols.

The preview updates as you edit and shows one label. Select the components and copies you need to download a single PDF, with one label per page and up to 1,000 pages.

Print at actual size (100%) on matching label stock. Your printer may have an unprintable border. Test-scan a label before printing a batch.
