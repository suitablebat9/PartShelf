# October 2026 usability improvements

Implemented from the supplied October 9 review:

- Parent storage searches include descendants; the scope selector can restrict results to the selected location. Storage uses a searchable tree with descendant counts. Normal locations can be renamed or moved; cycles are rejected. Organizer settings remain on their organizer page, and individual organizer drawers stay out of the storage tree.
- Basic component entry starts with name, quantity, unit, threshold, category and storage. Optional identifiers/tags, specifications, purchasing and attachments are collapsed. Internal part number replaces the Name_ID form label; existing data and label tokens are unchanged. Zero-stock parts can be saved without purchase details.
- Low stock uses each component's configured threshold, including equality. Needs restocking includes low stock and zero stock without thresholds. Summary links, badges and matching-result counts distinguish filtered results from workspace totals.
- Search/filter state travels with inventory component links and Back to results. Active filters can be removed individually.
- Projects preview build quantities and shortages, disable unavailable builds, and recheck stock transactionally on submission. A stale shortage returns to the project with a message. Multiple builds deduct the appropriate quantities. New builds have history and a one-time Undo action; undo returns exactly the deducted parts without changing the BOM. Builds before this update are not reconstructed. Deleted components prevent an old build from being undone, even if their database IDs are reused. History is included in workspace exports.
- Existing BOM rows have an explicit Edit affordance. Project search distinguishes Add from Update required quantity; component-detail additions show the current and resulting quantity.
- Label studio has starter templates, an Insert field menu, searchable/category-filtered batch selection, encoded-value display and inches/millimeters. PDF calculations remain in physical inches internally. Selected components remain selected when filtered out; Select matching adds only visible matches. Print guidance stays beside Download.
- Registration uses maker/team wording, a default editable workspace name, password guidance and a show-password control. Email verification immediately starts the new owner's session. Usernames remain supported and required; signup verification still enforces expiry, throttling and one-time use. Account settings link to password reset, and invitation role descriptions appear alongside role selection.
- Monetary displays consistently use dollars; inventory identifies USD. This does not add currency conversion or per-workspace currency selection. Stock/build timestamps show the browser's local timezone while preserving UTC in the tooltip.
- Welcome includes a real local sample-inventory screenshot, a three-step walkthrough and one support section. Empty roadmaps show one coming-soon state without invented commitments. Page titles and sidebar SVG icons are consistent. Empty About headings are omitted.
- Empty inventories offer setup links and omit empty search controls. Inventory exposes the existing owner/admin export. The demo notes account/team and organizer features available in personal workspaces.

Validation: automated regression coverage includes descendant filtering, moves/cycle rejection, numeric low-stock thresholds, minimal creation, search return safety, multi-build stock accounting, undo replay/deletion safety, viewer restrictions, signup session creation and physical label unit equivalence. Browser checks cover search context, minimal entry, disabled shortages, live metric previews, filtered selection, light/dark phone layouts and fixed-footer clearance.

The review's larger product opportunities remain separate: CSV/BOM import, supplier shopping-list export, duplication, bulk inventory actions, camera scanning and a general help center. No client data or reviewer test records were changed to populate public content.
